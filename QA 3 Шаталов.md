# Спринт 2: QA и DevOps задачи

## QA: Тест-кейсы

| ID | Кейс | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| **TC-01** | Корректная запись | Ввести валидные данные → Сохранить | Запись создана и отображается в списке. |
| **TC-02** | Пустые поля | Оставить поля пустыми → Сохранить | Ошибка валидации, запись не создана. |
| **TC-03** | Пробелы вместо текста | Ввести `"   "` → Сохранить | Пробелы обрезаются (trim), ошибка пустого поля. |
| **TC-04** | Повторная запись | Ввести данные существующей записи → Сохранить | Блокировка дубля (или создание с новым ID, согласно ТЗ). |
| **TC-05** | Удаление записи | Выбрать запись → Удалить → Обновить страницу | Запись удалена из UI и БД, не появляется после F5. |

## DevOps: Чек-лист проверки сборки после добавления файлов

- [x] **Git:** Проверить, что все новые файлы закоммичены и не скрыты в `.gitignore`.
- [x] **Билд:** Запустить чистую сборку без кэша (`--no-cache` / `clean build`) и убедиться в отсутствии ошибок импорта и путей.
- [ ] **Линтеры и тесты:** Убедиться, что новые файлы проходят проверку линтера и автотесты в CI/CD.
- [ ] **Артефакт:** Проверить наличие новых файлов/модулей в итоговой сборке или Docker-образе.
