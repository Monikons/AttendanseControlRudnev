# Спринт 5: QA и DevOps задачи

## QA: Тест-кейсы (Статистика и аналитика посещаемости)

| ID | Кейс | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| **TC-01** | Расчёт статистики по группе | Выбрать группу с сохранёнными отметками → Открыть «Статистику» | Количество и процент статусов «Присутствовал», «Отсутствовал», «Опоздал» совпадают с данными в БД. |
| **TC-02** | Расчёт по конкретному студенту | Выбрать студента в фильтре → Проверить показатели | Отображается индивидуальная сводка только по занятиям выбранного студента. |
| **TC-03** | Пустая база / нет занятий | Выбрать группу без проведённых занятий | Ошибки деления на ноль нет, выводится сообщение *«Нет данных для отображения»*. |
| **TC-04** | Актуализация после новой отметки | Сохранить новое занятие → Перейти в «Статистику» | Счётчики и проценты обновились автоматически без перезапуска приложения. |
| **TC-05** | Удаление студента или занятия | Удалить студента из группы → Проверить сводку по группе | Записи удалённого студента исключены из общего расчёта статистики. |

## DevOps: Чек-лист проверки сборки после добавления модуля статистики

- [x] **Git:** Проверить, что файлы экрана статистики, разметки и DAO-запросов закоммичены в репозиторий.
- [x] **Билд:** Выполнить чистую пересборку проекта (`Clean Project` → `Rebuild Project`) без ошибок компиляции.
- [x] **Миграции и БД:** Проверить корректность SQL-запросов агрегации в Room на пустой и заполненной базе.
- [ ] **Линтеры и тесты:** Запустить Android Lint и unit-тесты расчёта процентов.
- [ ] **Артефакт:** Собрать отладочный APK и проверить работу экрана статистики на эмуляторе.
