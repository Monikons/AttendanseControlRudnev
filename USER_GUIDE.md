# Руководство пользователя

## 1. Назначение

«Система контроля посещаемости студентов» предназначена для преподавателя или куратора учебной группы. С её помощью можно вести список студентов, фиксировать посещаемость занятий и просматривать сохранённые результаты.

Приложение рассчитано на локальное использование на одном Android-устройстве. Для основной работы постоянное подключение к интернету не требуется.

> Руководство описывает предусмотренный порядок работы с приложением. Отдельные пункты становятся доступны по мере реализации соответствующих экранов и функций.

## 2. Запуск приложения

1. Установите приложение на Android-устройство или запустите его через Android Studio на эмуляторе.
2. Откройте приложение.
3. После запуска должен появиться главный экран с разделами:
   - «Студенты»;
   - «Отметить посещаемость»;
   - «Статистика».

Если приложение не запускается, сообщите об ошибке разработчику. При запуске из Android Studio дополнительную информацию можно посмотреть в окнах **Build** и **Logcat**.

## 3. Работа со списком студентов

### Просмотр списка

1. На главном экране откройте раздел «Студенты».
2. Просмотрите список добавленных записей.
3. В карточке студента должны отображаться фамилия, имя и учебная группа.

Если список пуст, сначала добавьте студентов.

### Добавление студента

1. Откройте раздел «Студенты».
2. Выберите действие добавления.
3. Заполните поля:
   - фамилия;
   - имя;
   - учебная группа.
4. Проверьте введённые данные и сохраните запись.

Все три поля обязательны. Не оставляйте их пустыми и не вводите вместо текста одни пробелы. Если приложение сообщает об ошибке, исправьте данные и повторите сохранение.

### Удаление студента

1. Найдите нужную запись в списке.
2. Выберите действие удаления.
3. Проверьте, что выбран правильный студент.
4. Подтвердите удаление или отмените действие.

Удаление следует выполнять внимательно. Перед реализацией этой функции команда должна определить, как обрабатываются отметки посещаемости, связанные с удаляемым студентом.

## 4. Создание занятия

Чтобы отметить посещаемость, сначала выберите или создайте занятие.

1. Откройте раздел отметки посещаемости.
2. Перейдите к созданию занятия.
3. Укажите дату.
4. Введите дисциплину или тему занятия.
5. Сохраните запись.

Дата и дисциплина/тема нужны для того, чтобы впоследствии отличать одну ведомость от другой.

## 5. Отметка посещаемости

1. Выберите нужное занятие.
2. Убедитесь, что открыт список нужной учебной группы.
3. Для каждого студента выберите один из статусов:
   - **Присутствовал** — студент посетил занятие;
   - **Отсутствовал** — студент не присутствовал;
   - **Опоздал** — студент пришёл после начала занятия.
4. При необходимости добавьте комментарий.
5. Сохраните отметки.

После сохранения проверьте несколько записей повторным открытием занятия. Это позволит убедиться, что статусы действительно записались.

Для одного студента в рамках одного занятия должна храниться одна актуальная отметка. Если статус был выбран неправильно, его следует исправить, а не создавать вторую противоречащую запись.

## 6. Просмотр истории

История нужна, чтобы проверить отметки за прошедшие занятия.

1. Откройте карточку студента или предусмотренный раздел истории.
2. Найдите нужную дату.
3. Проверьте дисциплину/тему и статус.

Если записей нет, проверьте, были ли занятия созданы и сохранены ли отметки.

## 7. Просмотр статистики

1. На главном экране откройте раздел «Статистика».
2. Просмотрите доступную сводку.
3. При необходимости сопоставьте показатели с отдельными записями посещаемости.

Статистика должна рассчитываться по сохранённым отметкам. Статусы «Присутствовал», «Отсутствовал» и «Опоздал» учитываются отдельно.

## 8. Рекомендации по вводу данных

- Проверяйте фамилию, имя и группу перед сохранением.
- Указывайте дату занятия и понятное название дисциплины или темы.
- Не создавайте повторное занятие, если нужная запись уже существует.
- После отметки группы проверяйте, что изменения сохранены.
- Комментарий используйте только для дополнительной информации; он не заменяет статус посещаемости.

## 9. Если что-то пошло не так

| Ситуация | Что проверить |
| --- | --- |
| Не удаётся добавить студента | Заполнены ли фамилия, имя и группа; нет ли в поле одних пробелов |
| Студент не отображается в списке | Завершилось ли сохранение; обновился ли экран |
| Не сохраняется отметка | Выбрано ли занятие и установлен ли статус |
| После перезапуска нет данных | Проверить реализацию локального хранения и сообщения об ошибках |
| Приложение закрывается | Зафиксировать последовательность действий и передать её разработчику |

При сообщении об ошибке полезно указать модель устройства или версию эмулятора, последовательность действий и текст сообщения. Если ошибка воспроизводится, не удаляйте данные приложения до выяснения причины.

## 10. Важные ограничения

- Приложение предназначено для локальной работы на одном устройстве.
- Автоматическая синхронизация между несколькими телефонами не предусмотрена базовым планом.
- Облачное хранение, учётные записи и распределение прав пользователей не входят в обязательный объём первой версии.
- Набор доступных экранов зависит от текущего этапа разработки.
